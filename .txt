Program4: Joining a thread

th1.Start();
th1.Join();
Console.WriteLine("resource={0}", resource);

Join() pauses the calling thread until the selected thread finishes.

The sequence is:

Main starts th1
    ↓
Main waits at Join()
    ↓
th1 increments resource 8,555 times
    ↓
th1 finishes
    ↓
Main continues and prints resource

The initial value is 1000, so:

1000 + 8555 = 9555

Therefore, the final output ends with:

resource=9555

The main difference between Programs 3 and 4 is:

Thread.Sleep(1000); // Waits for an amount of time
th1.Join();         // Waits until th1 actually finishes

When you need to wait for a thread’s work, Join() is reliable; Sleep() is only a timed pause.
