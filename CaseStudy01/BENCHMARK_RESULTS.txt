CPU INFORMATION
---------------

CPU model: Intel(R) Core(TM) Ultra 7 155H

Hybrid core configuration:
- 6 Performance cores (P-cores)
  - 2 threads per core using Hyper-Threading
  - 12 logical processors in total

- 8 Efficient cores (E-cores)
  - 1 thread per core
  - 8 logical processors in total
  - Maximum frequency reported by the system: up to 3.8 GHz

- 2 Low-Power Efficient cores (LP E-cores)
  - 1 thread per core
  - 2 logical processors in total
  - Maximum frequency reported by the system: up to 2.5 GHz

Total: 6 P-cores + 8 E-cores + 2 LP E-cores = 16 physical cores
       12 P-core threads + 8 E-core threads + 2 LP E-core threads
       = 22 logical processors


BENCHMARK METHOD
----------------

- The original program was run three times to establish the baseline.
- The adjusted program was run three times with 2, 4, 8, 16, and 22 threads.
- Each adjusted run used manually managed threads and static range scheduling.
- Both programs performed the same workload: 10,000,000 values over 30 rounds.
- The reported calculation time excludes data-loading time.
- Speedup was calculated as:

    Original average time / Adjusted average time

SUMMARY
-------

Fastest average:
- 22 threads
- Average time: 2,563.67 ms
- Speedup: 8.28x faster than the original code

Slowest adjusted thread configuration:
- 2 threads
- Average time: 11,041.67 ms
- Speedup: 1.92x faster than the original code

Fastest individual run:
- 22 threads, Run 1
- Time: 2,510 ms

Comparison of 16 and 22 threads:
- 22 threads was only 6.33 ms, or approximately 0.25%, faster on average.
- Therefore, their measured performance was nearly identical.

Correctness:
- Every original and adjusted run produced the same result:
  4,686,980,924,312.00


CONCLUSION
----------

The adjusted multithreaded code was faster than the original code at every
tested thread count. Performance improved as the number of threads increased,
although the improvement became very small between 16 and 22 threads. The
fastest tested configuration was 22 threads, with an average execution time of
2,563.67 ms and a speedup of 8.28x over the original code.
